# 브리핑 평가 세트 (P1-17 · `-95`)

지표 세트 30건. **환각 숫자 0건이 절대 기준**이다.

## 라벨이 없다 — 거래 분류와 다른 점

거래 분류(`p1-01`)는 사람이 정답 카테고리를 붙여야 채점이 된다. 브리핑은 아니다.
재는 것이 *"좋은 문장인가"* 가 아니라 *"입력에 없는 숫자를 지어냈는가"* 이고, 그 판정은
입력 `metrics` 만 있으면 **결정적으로** 내려진다 (`app/nlp/briefing.py`).

그래서 이 세트에는 정답 문장이 없고 **입력만** 있다. 사람 라벨링이 필요 없다.

## 무엇을 재나

| 지표 | 뜻 | 기준 |
| --- | --- | --- |
| `hallucinatedSentences` | 검증기가 버린 문장 수 | **0 이어야 한다** |
| `partialRate` | 문장이 하나라도 버려진 브리핑 비율 | 낮을수록 좋다 |
| `totalLossRate` | 전부 버려져 본문이 사라진 비율 | 0 이어야 한다 |
| `headlineDropRate` | headline 이 중립 제목으로 바뀐 비율 | 낮을수록 좋다 |

**"환각 0건" 이 자동으로 참이 되는 함정을 피해야 한다.** 검증기가 다 버리면 사용자에게
가는 환각은 0 이지만 브리핑도 0 이다. 그래서 폐기율을 함께 재고, 그것이 **프롬프트 품질의
실제 지표**다. 이 세트가 재는 것은 검증기가 아니라 **프롬프트**다.

## 함정 — 일부러 심었다

모델이 숫자를 지어내고 싶게 만드는 입력이 아니면 0 건이 나와도 아무것도 증명하지 못한다.

| 유형 | 왜 위험한가 | 예 |
| --- | --- | --- |
| **합산 유도** | 지표 둘을 더하고 싶어진다. 도메인 규칙 2 위반 | 매출·비용을 같이 주고 "남는 돈" 을 유도 |
| **반올림 유도** | `748,231` 을 "약 75만원" 으로 쓰고 싶어진다 | 끝자리가 지저분한 금액 |
| **비율 계산 유도** | 두 값에서 증감률을 직접 계산하고 싶어진다 | `changeRate` 없이 전·후 값만 |
| **날짜 추론 유도** | "9월 14일" 에서 "다음 주" 나 "3일 뒤" 를 만들고 싶어진다 | 날짜 하나만 주기 |
| **라벨 속 숫자** | `향후 30일` 의 30 은 인용이지 창작이 아니다 — 오탐 확인용 | 라벨에 숫자 포함 |
| **빈 맥락** | 지표 1건뿐. 채우려고 없는 말을 만든다 | 단일 지표 |

## 돌리는 법

```bash
uv run --frozen python -X utf8 -m evals.run_briefing_eval          # 유료
uv run --frozen python -X utf8 -m evals.run_briefing_eval --dry-run
```

결과는 `report.json` 으로 커밋되고 `tests/nlp/test_briefing_eval_report.py` 가 기준을
검사한다. 리포트가 없으면 그 테스트는 건너뛴다.

## 한계

지표 세트는 **합성 데이터**다. 실제 계산 엔진(P1-19 월별 리포트·P1-22 매출 구성비)이
붙으면 그쪽 출력으로 바꿔 다시 뽑는다. 지금 값은 금액 규모와 필드 조합을 실제와 비슷하게
맞췄을 뿐 실제 사업장 수치가 아니다.
