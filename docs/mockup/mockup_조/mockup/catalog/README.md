# 잔고예보 와이어프레임 보강본 v2

화면구성도(A1~J6)에는 있으나 프로토타입에 없던 화면과, UX/UI·디자인 검토보고서의 지적을 해결하는 화면을 모은 **명세 카탈로그**다.

## 이전 버전과 달라진 것

v2 첫 판은 기존 화면을 건드리지 않기 위해 **별도의 스타일 시트를 새로 만들었다.** 그 결과 하나의 서비스에 두 벌의 디자인 시스템이 생겼고, 디자인 검토보고서가 이를 **D-01(P0)** 로 지적했다.

지금은 이 파일이 프로토타입과 **같은 `../design-system.css` 한 벌**을 쓴다. 토큰·컴포넌트·반응형 규칙이 모두 공유된다.

| 항목 | 이전 | 지금 |
| --- | --- | --- |
| 스타일 원본 | 이 파일 안 `<style>` 190줄 | `../design-system.css` 공유 |
| 인라인 `style` | 288개 | **14개** (전부 스켈레톤·막대 폭 같은 데이터 표현) |
| 인라인 열 정의 | 54개 | **0개** (`.list`의 `--cols` 프리셋 6종) |
| 인라인 `font-size` | 48개 | **0개** |
| 미디어/컨테이너 쿼리 | 0개 | 프레임에 컨테이너 쿼리 — 아트보드 폭으로 규칙이 실제로 돈다 |
| 배지 형태 | 알약, 테두리 없음 | 사각 6px + 테두리 (프로토타입과 동일) |
| 페이지 타이틀 | topbar 안 15px | 콘텐츠 최상단 `h1` 24px |
| 금액 색 | 입금 파랑 / 출금 주황 | 전부 `--ink`. 부호와 정렬로 방향을 말한다 |

### Foundation (아트보드 아님)

**화면 상태 규칙** — 불러오는 중 · 없음 · 오류 · 못 누름 · 완료 · **포커스** 여섯 가지 견본. 화면이 아니라 규칙이므로 아트보드 레일 밖에 따로 둔다. Figma에서도 화면 페이지가 아니라 `Foundation` 페이지에 놓는다.

## 특히 봐야 할 것

**태블릿 아트보드 (D-04)** — 1180px 아트보드와 **마크업이 완전히 같다.** 폭만 1000px다. 프레임에 컨테이너 쿼리를 걸어 두어서, 사이드바가 아이콘만 남고 목록+상세 2단이 1단으로 접히는 것을 그 자리에서 볼 수 있다. 좁은 폭 규칙이 문서가 아니라 코드로 존재한다.

**모바일 거래 목록 (P0-4)** — 이전 프로토타입은 `760px` 이하에서 4번째 열부터 숨겨 **금액이 통째로 사라졌다.** 열을 자르는 대신 카드로 바꿔 금액을 가장 크게 두고 분류·영수증 배지를 살렸다.

**정산 맞춰 보기 (P0-3)** — `매출 − 취소·환불 − 수수료 = 정산서대로면 들어올 돈` 계산을 표로 펼쳐 놓고 실제 입금과의 차이를 마지막 줄에 둔다. 차이가 날 때 원인 후보 세 가지를 함께 적되, 서비스가 원인을 확정하지 않는다. 세로로 쌓지 않고 **목록 + 상세 2단**이라 화면 안에서 대조가 끝난다.

**알림 센터 (P1-9)** — 거래 상세와 **같은 Drawer 컴포넌트**를 쓴다. 배경 blur를 빼고 scrim 하나만 남겼다. 알림의 다음 행동은 배지가 아니라 버튼이다 — 배지는 상태만 뜻한다.

## 지키기로 한 규칙

`../README.md`의 "지키기로 한 것"과 같다. 두 파일이 같은 규칙을 쓴다.

## Figma로 옮기기

1. `python -m http.server 4173 -d wireframe`
2. Figma에서 html.to.design 계열 플러그인으로 `http://localhost:4173/v2/` 를 가져온다. 폭은 **1720px**.

> **이전 안내와 달라진 점** — v2 첫 판은 이 카탈로그를 `x = 28140`의 **세 번째 섹션**에 놓으라고 안내했다. 그러면 Figma 파일 안에 두 벌의 디자인 시스템이 영구히 남는다(D-01).
>
> 지금은 **기존 `pc`·`mobile` 섹션을 프로토타입(`wireframe/`)에서 다시 가져온 것으로 교체**하고, 이 카탈로그는 그 옆에 **신규 화면 명세**로만 놓는다. 두 섹션이 같은 토큰을 쓰므로 나란히 두어도 한 서비스로 보인다.
>
> `화면 상태 규칙`은 화면 섹션이 아니라 `Foundation` 페이지로 옮긴다.

> Figma MCP는 Starter 플랜에서 **월 20회**만 호출할 수 있다. 화면 하나가 노드 100~250개라 직접 그리는 방식은 한도 안에서 두세 화면이 한계다. 플러그인으로 가져오는 방법을 먼저 쓸 것.
