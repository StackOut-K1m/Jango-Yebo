# P0·P1 적용 범위

| 기능 | 2안 적용 위치 |
|---|---|
| P0-01~02 수집·분류 | 거래·예정의 CSV 가져오기, 거래 목록, AI 분류 상태 |
| P0-03~05 반복 탐지·추천·확인 | 거래·예정의 반복 후보, 다음 날짜·금액 범위, 승인·수정 |
| P0-06 일회성 예정 거래 | 전역 `예정 거래` 버튼과 등록 모달 |
| P0-07~08 예상 잔액·부족 알림 | 오늘의 자금 예보, 7/30일 예보, 자금주의보와 알림 센터 |
| P0-09·13 시나리오 | 지연·감액·추가 지출 조합, 결과 비교, 저장·예정 거래 전환 |
| P0-10 증빙 | 업로드, 목록–상세, 거래 매칭 |
| P0-11 정산 대사 | 매출−환불−수수료와 실제 입금 비교, 차이 원인·확정 |
| P0-12 신고자료 | 기간·형식·점검·생성 진행 상태 |
| P1-01 자동 분류 | 분류 신뢰도, 추정 근거, 낮은 신뢰도 확인 |
| P1-02~03 증빙 인식·품목 | OCR/VLM 편집 필드, 품목 지출과 단가 추이 |
| P1-04~07 예보 보정 | 휴일 지연 근거, 예측 정확도, 원자재 지표, 계절성 |
| P1-08~09·11 안전선·준비금·부가세 | 오늘 잔고 구성과 운영 기준 편집 화면 |
| P1-12 다사업장·계좌 | 사업장 전환, 계좌 상태, 매장 간 가상 이동 시뮬레이션 |
| P1-13~16 금융 대응 | 대출 현황, 신용 상품, 지원제도, 발급 링크·AI 문서 편집 |
| P1-17·19 브리핑·월간 피드백 | 근거 기반 AI 브리핑, 수입·지출·현금흐름 비교 |
| P1-18 캘린더 | 수입·지출·세금 일정과 날짜 상세 |

P1-10, P1-20, P1-21은 SRS v1.2에서 각각 P0-13, P2-14, P2-15로 이동한 결번이므로 별도 기능으로 중복 구현하지 않았다.
