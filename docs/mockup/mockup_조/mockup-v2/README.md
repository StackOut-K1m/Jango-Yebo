# 잔고예보 목업 2안

기존 `wireframe/`을 유지한 채 별도 제작한 **자금 예보 워크스페이스**다. 홈은 카드형 대시보드가 아니라 현재 상태에서 대응 업무까지 이어지는 판단 흐름으로 구성한다.

- `index.html`: 데스크톱 전용 2안
- `mobile.html`: 모바일 과업 흐름에 맞게 다시 구성한 모바일 전용 2안
- `styles.css`: 공통 토큰과 각 폼팩터 레이아웃
- `app.js`: 해시 라우팅, 탭, 모달, 알림, 시나리오 입력 등 대표 상호작용

## 설계 원칙

1. 카드 반복을 줄이고 `현재 상태 → 7일 예보 → 오늘 흐름 → 브리핑 → 확인 업무`가 세로 흐름으로 이어진다.
2. 일기예보의 조건·시간대·주간 전망·주의보 문법을 현금흐름에 적용한다.
3. 상태는 색만으로 표현하지 않고 `주의`, `안전잔고 하회`, 금액·날짜·회복일을 함께 쓴다.
4. P0-01~13과 P1-01~19(결번 제외)를 거래, 예보, 시뮬레이션, 증빙·신고, 캘린더, 브리핑·금융, 운영 기준 화면에 모두 배치했다.
5. 모바일은 데스크톱 열을 감추지 않고 거래 금액·분류·상태가 유지되는 별도 화면을 제공한다.

## 실행

프로젝트 루트에서:

```bash
python -m http.server 4174 -d wireframe-v2
```

- 데스크톱: `http://localhost:4174/`
- 모바일: `http://localhost:4174/mobile.html`
