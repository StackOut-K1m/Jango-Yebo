**서버 없이 `index.html` 을 더블클릭해도 열립니다.** 바깥에서 가져오는 것이 글꼴뿐이라 그렇습니다.

## 이 판으로 무엇을 하나

**팀에서 화면을 나눠 맡을 때 봅니다.** 화면 하나마다 「이 화면이 맡는 기능」이 옆에 붙어 있고,
각 기능이 지금 **있음 · 부분 · 없음** 중 무엇인지 적혀 있습니다.

- **「없음」이 곧 할 일**입니다. 감추지 않았습니다 — 감추면 팀이 "이미 됐다"고 여기고 아무도 안 만듭니다.
- 상단 **「할 일 있는 화면만」** 을 누르면 손볼 게 남은 화면만 남습니다.
- 맨 아래 **「화면이 없는 기능」** 열 건이 **만들어야 할 화면** 목록입니다.

화면 하나를 혼자 열어도 **맨 아래에 같은 기능 띠**가 붙어 있습니다.
어두운 띠라 여기부터는 사장에게 보이는 화면이 아니라 팀에게 보이는 메모임을 표시합니다.
실제 구현에서는 이 띠를 지웁니다.

### 화면을 고친 뒤에 할 일

**`features.js` 의 `SCREEN_FEAT` 를 함께 고칩니다.**
개수와 진행은 전부 그 표에서 세므로, 표만 맞으면 `index.html` 과 각 화면의 기능 띠가 따라옵니다.
문구에 숫자를 박아 두지 않았습니다.

그리고 **`_check.html` 을 한 번 돌립니다.** 탭 제목이 `PASS 24` 면 정상입니다.
스크립트가 죽었는지 · `undefined`/`NaN` 이 찍혔는지 · 상태 뱃지에 모양과 글자가 함께 있는지(화면구성도 6.1)를 봅니다.

> 이 도구가 실제로 하나 잡았습니다 — `pc-export` 가 「단계 제목」에 `.st` 를 써서
> `sky.css` 의 상태 뱃지 스타일과 충돌하던 것.
