## 17. 지원 제도와 서류 안내

### 17.1 지원 제도 검색 (P1-15)

`GET /support-programs?q=광주 카페 사장이 지금 받을 수 있는 임대료 지원&region=광주&industryType=FOOD_CAFE&supportType=FUNDING&deadlineAfter=2026-09-01&sort=MATCH_SCORE&page=0&size=20`

| Query | 설명 |
| --- | --- |
| `q` | 키워드 또는 자연어 질의. 자연어는 임베딩 검색(RAG)으로 상세요강까지 검색한다 |
| `region`, `industryType` | 지역·업종 필터 |
| `supportType` | `FUNDING`(융자), `SUBSIDY`(보조금), `VOUCHER`(바우처), `CONSULTING`, `OTHER` |
| `deadlineAfter` | 이 날짜 이후 마감인 공고만 |
| `sort` | `MATCH_SCORE`, `DEADLINE`, `COLLECTED_AT` |

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "programId": 1201,
        "title": "2026 광주광역시 소상공인 임대료 특별지원",
        "organizer": "광주광역시",
        "sourceSite": "BIZINFO",
        "sourceUrl": "https://www.bizinfo.go.kr/...",
        "collectedAt": "2026-08-31T00:30:00Z",
        "supportType": "SUBSIDY",
        "maxAmount": 3000000,
        "interestRate": null,
        "applyStart": "2026-09-01",
        "applyEnd": "2026-09-19",
        "eligibilitySummary": {
          "regions": ["광주"],
          "industries": ["요식업 포함 전 업종"],
          "maxAnnualRevenue": 300000000,
          "notes": ["업력 1년 이상"]
        },
        "matchScore": 0.91,
        "needsVerification": true
      }
    ],
    "page": 0,
    "size": 20,
    "totalElements": 4,
    "totalPages": 1
  }
}
```

- 공고는 기업마당(bizinfo)·중소벤처24·K-Startup·소진공에서 매일 배치로 수집하고, LLM이 지원 대상 조건·금액·기간·서류를 정형 필드로 구조화한다(20.2).
- 원문 링크(`sourceUrl`)와 수집일(`collectedAt`)을 항상 병기하고, 조건이 불명확한 공고는 `needsVerification = true`로 표시한다. 최종 자격 판단은 기관 확인이 필요하다는 문구를 상세 화면에 고정 노출한다.

### 17.2 지원 제도 상세

`GET /support-programs/{programId}`

목록 필드에 더해 다음을 포함한다.

```json
{
  "success": true,
  "data": {
    "programId": 1201,
    "rawSummary": "공고 원문 요약...",
    "eligibility": {
      "regions": ["광주"],
      "industries": ["전 업종"],
      "maxAnnualRevenue": 300000000,
      "minYearsInBusiness": 1,
      "maxYearsInBusiness": null,
      "excludes": ["휴·폐업자", "국세 체납자"],
      "uncertainConditions": ["공동사업자 신청 가능 여부"]
    },
    "expectedDisbursementDays": 30,
    "requiredDocuments": [
      {
        "documentName": "사업자등록증명",
        "issuer": "홈택스",
        "issueUrl": "https://hometax.go.kr/...",
        "method": "온라인 즉시 발급",
        "fee": 0
      },
      {
        "documentName": "부가가치세과세표준증명",
        "issuer": "홈택스",
        "issueUrl": "https://hometax.go.kr/...",
        "method": "온라인 즉시 발급",
        "fee": 0
      }
    ]
  }
}
```

- `uncertainConditions`는 구조화 과정에서 확신할 수 없어 "확인 필요"로 표시하는 조건이다.
- `requiredDocuments`는 서류 사전(17.4)과 연결되어 발급 링크를 제공한다 (P1-15).

### 17.3 맞춤·공백 연계 추천

`GET /businesses/{businessId}/support-programs/recommendations?cashGapLinked=true`

```json
{
  "success": true,
  "data": {
    "baseTime": "2026-08-31T02:00:00Z",
    "profile": {
      "region": "광주 서구",
      "industryType": "FOOD_CAFE",
      "annualRevenue": 88000000,
      "yearsInBusiness": 3
    },
    "cashGap": {
      "firstShortfallDate": "2026-09-14",
      "maxShortfallAmount": 800000
    },
    "items": [
      {
        "programId": 1201,
        "title": "2026 광주광역시 소상공인 임대료 특별지원",
        "matchScore": 0.91,
        "matchedConditions": ["지역", "업종", "매출 상한"],
        "applyEnd": "2026-09-19",
        "expectedDisbursementDays": 30,
        "canArriveBeforeGap": false,
        "timingNote": "집행까지 약 30일 소요되어 9월 14일 공백 이전 수령은 어려울 수 있습니다."
      }
    ],
    "disclaimer": "자격 충족 여부는 주관 기관 확인이 필요합니다."
  }
}
```

- `cashGapLinked = true`이면 가장 가까운 정산 공백을 기준으로 신청 마감일과 집행 소요 기간을 역산해 `canArriveBeforeGap`을 계산한다 (P1-15 공백 연계 알림).
- 공백 감지 시 서버는 이 결과를 근거로 `CASH_GAP` 알림의 `suggestions`에 지원 제도 후보를 포함한다.

### 17.4 서류 발급처 사전 (P1-15)

`GET /document-guides?programId=1201` 또는 `GET /document-guides?q=사업자등록증명`

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "documentGuideId": 301,
        "documentName": "사업자등록증명",
        "issuer": "홈택스",
        "issueUrl": "https://hometax.go.kr/...",
        "method": "온라인 즉시 발급",
        "fee": 0,
        "estimatedTime": "즉시",
        "notes": "공동인증서 필요"
      }
    ]
  }
}
```

- 발급 자동화(대리 발급)는 범위에서 제외하며 발급처 링크와 안내만 제공한다.

### 17.5 (결번) AI 문서 템플릿 편집기

v1.5에서 범위 제외(P1-16 결번). 지원사업 신청 문서(사업계획서 등)의 템플릿 목록, 문서 생성·저장, AI 문장 보조(`ai-assist`), DOCX/PDF 내보내기 API를 삭제했다. "민감 항목은 AI에 전달하지 않고 사용자가 직접 입력한다"는 원칙과 문장 보조 워커(20.10)는 **14.3 종합소득세 신고서 초안**으로 이어진다. 이전 정의는 git 이력(API v1.4)을 참고한다.
